# Autonomous Multi-Task Assistant Robot

**Degree:** Bachelor of Technology in Electronics and Communication Engineering (2026)[cite: 1]

**Supervisor:** Prof. (Dr.) Arpita Chakraborty[cite: 1]  

## 📌 Project Overview
An intelligent, voice-controlled personal assistant robot capable of mobility, live surveillance streaming, spatial telemetry, and autonomous material transport[cite: 1]. High-level AI processing (Google Gemini) is decoupled from low-level motor actuation across four independent hardware subsystems[cite: 1].

## 🛠️ Hardware Subsystems
1. **Locomotion Subsystem:** Arduino UNO R3 + L293D Motor Shield + 4x TT Gear Motors + HC-05 Bluetooth[cite: 1].
2. **Telemetry Subsystem:** Arduino Nano + HC-SR04 Ultrasonic Sensor + 9g Servo + 1.3" I2C OLED Display[cite: 1].
3. **Vision Subsystem:** ESP32-CAM (SoftAP Wi-Fi live streaming)[cite: 1].
4. **AI Audio Subsystem:** Smartphone Gateway (Google Gemini AI) + Bluetooth A2DP Audio Receiver + 3W Speaker[cite: 1].
